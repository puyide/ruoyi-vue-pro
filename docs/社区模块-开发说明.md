# 社区模块开发说明

## 概述

本文档描述了「星语家园」社区帖子功能的技术实现，采用三层架构：

```
小程序 → ruoyi-vue-pro（API 中间层）→ NodeBB
```

小程序不直接连接 NodeBB，所有请求通过 ruoyi-vue-pro 进行转发和处理。

## MVP 功能范围

### 已实现功能

1. **帖子列表**（含分类/标签筛选）
2. **帖子详情**（楼层列表）
3. **点赞/收藏/关注**
4. **发帖/回帖**（含图片）
5. **我的帖子/我的回复**
6. **通知红点计数**

## 内容审核

### ContentModerationService

提供以下审核能力：

1. **敏感词过滤** - 检测并拒绝包含敏感词的内容
2. **隐私信息检测** - 检测手机号、微信号、QQ号、邮箱（警告不阻止）
3. **长度校验** - 标题最少5字，正文最少20字
4. **图片处理** - 将图片URL转换为Markdown格式插入内容

### 敏感词配置

当前敏感词存储在代码中，建议后续改为：
- 数据库存储
- 或配置文件加载
- 或接入第三方审核API

## 配置要求

### NodeBB 配置

在 `application.yaml` 中配置：

```yaml
yudao:
  member:
    nodebb:
      enabled: true
      url: http://localhost:4567
      master-token: your-master-token
      admin-uid: 1
      sso-secret: your-sso-secret
```

### NodeBB Master Token 获取

1. 登录 NodeBB 管理后台
2. 进入 Settings → API Access
3. 创建新的 Master Token
4. 配置到 ruoyi

## 用户映射

### 映射表

`member_nodebb_user` 表存储用户映射关系：

| 字段 | 说明 |
|------|------|
| user_id | ruoyi 用户ID |
| nodebb_uid | NodeBB 用户ID |
| username | NodeBB 用户名 |

### 自动同步

当用户首次使用社区功能时，系统会自动：
1. 检查是否存在 NodeBB 用户
2. 如不存在，调用 NodeBB API 创建用户
3. 保存映射关系

### 后端接口

| 方法 | 路径 | 说明 | 权限 |
|------|------|------|------|
| GET | `/member/community-admin/topic/page` | 获取帖子列表 | member:community:query |

| PUT | `/member/community-admin/topic/update-status` | 更新帖子状态 | member:community:update |
| DELETE | `/member/community-admin/topic/delete` | 删除帖子 | member:community:delete |
| GET | `/member/community-admin/post/page` | 获取回帖列表 | member:community:query |
| PUT | `/member/community-admin/post/audit` | 审核回帖 | member:community:audit |
| DELETE | `/member/community-admin/post/delete` | 删除回帖 | member:community:delete |

### 前端页面

| 路径 | 说明 |
|------|------|
| `/views/member/community/topic/index.vue` | 帖子管理列表 |
| `/views/member/community/topic/TopicDetailDialog.vue` | 帖子详情弹窗 |
| `/views/member/community/post/index.vue` | 回帖管理列表 |

### 权限配置

执行 `sql/postgresql/community_menu.sql` 添加菜单和权限：

- `member:community:query` - 查看帖子/回帖
- `member:community:audit` - 审核帖子/回帖
- `member:community:update` - 更新帖子状态（置顶/锁定）
- `member:community:delete` - 删除帖子/回帖

### 功能说明

1. **帖子管理**
   - 查看所有帖子列表，支持按ID、标题、时间筛选
   - 查看帖子详情（标题、内容、作者、统计数据）
   - 置顶/取消置顶帖子
   - 锁定/解锁帖子（禁止回复）
   - 删除违规帖子

2. **回帖管理**
   - 查看所有回帖列表
   - 查看回帖详情和所属帖子
   - 删除违规回帖
