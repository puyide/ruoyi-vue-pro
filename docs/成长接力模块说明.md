# 成长接力模块 - 器材交易功能

## 一、功能概述

成长接力是康复训练器材共享平台的核心功能，支持用户之间分享、借用、转让康复训练器材。

### 三种交易模式

| 模式 | 代码 | 说明 | 是否需要归还 | 是否需要付款 |
|-----|------|------|-------------|-------------|
| 赠送 | `give` | 免费赠送给需要的家庭 | 否 | 否 |
| 借用 | `borrow` | 借用一段时间后归还 | 是 | 否 |
| 低价转让 | `sell` | 低于市场价转让，价格面议 | 否 | 是（线下支付） |

### 低价转让支付流程

> ⚠️ 平台不参与资金流转，买卖双方通过微信/支付宝等方式私下转账

```
1. 买卖双方协商价格
2. 买家通过微信/支付宝转账给卖家
3. 买家上传转账凭证截图
4. 卖家确认收款
5. 双方进行物品交接
```

### 器材类型

| 类型代码 | 名称 |
|---------|------|
| `language` | 语言训练 |
| `sensory` | 感统训练 |
| `attention` | 注意力 |
| `social` | 社交 |
| `emotion` | 情绪管理 |
| `other` | 其他 |

## 二、业务流程

```
┌─────────────────────────────────────────────────────────────────┐
│                        成长接力完整流程                           │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  1. 发布好物                                                    │
│     └─ 用户发布闲置器材，选择交易方式（赠送/借用/低价转让）          │
│           │                                                     │
│           ▼                                                     │

│     └─ 管理员审核发布内容                                        │
│           │                                                     │

│           │                                                     │
│           ▼                                                     │
│  4. 发起接力申请                                                 │
│     └─ 感兴趣的用户发送申请，说明用途                             │
│           │                                                     │
│           ▼                                                     │
│  5. 处理申请                                                     │
│     └─ 发布者同意或拒绝申请                                      │
│           │                                                     │
│           ▼ (同意)                                               │
│  6. 交换联系方式                                                 │
│     └─ 双方确认后交换微信号                                      │
│           │                                                     │
│           ▼                                                     │
│  7. 线下交接                                                     │
│     └─ 当面交接 或 快递寄送                                      │
│           │                                                     │
│           ▼                                                     │
│  8. 确认交接                                                     │
│     └─ 双方确认交接完成                                          │
│           │                                                     │
│           ▼                                                     │
│  9. 发送感谢                                                     │
│     └─ 接收方向赠送方发送感谢                                    │
│           │                                                     │
│           ▼ (如果是借用)                                         │
│  10. 归还器材                                                    │
│      └─ 借用方在约定时间归还                                     │
│                                                                 │

```

## 五、状态流转

### 5.1 好物状态

```
待审核(0) → 接力中(1) → 已匹配(2) → 交接中(3) → 已完成(4)
              ↓
         审核拒绝(5)
              ↓
         已下架(6)
```

### 5.2 申请状态

```
待处理(0) → 已同意(1) → 已完成(4)
    ↓
已拒绝(2)
    ↓
已取消(3)
```

## 七、安全设计

### 7.1 隐私保护

- 申请留言禁止包含手机号
- 申请留言禁止包含地址信息
- 联系方式（微信）仅在双方同意后才能交换
- 用户可以选择是否公开感谢内容
