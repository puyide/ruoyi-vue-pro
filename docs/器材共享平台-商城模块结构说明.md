# 康复训练器材共享平台 - 商城模块结构说明

## 一、模块概述

器材共享平台的功能被整合到了现有的商城系统模块中，具体分布如下：

| 功能模块 | 所属模块 | 说明 |
|---------|---------|------|
| 信用积分 | yudao-module-member | 会员信用分管理 |
| 器材预约 | yudao-module-product | 器材(SPU)预约功能 |
| 交接会话 | yudao-module-trade | 器材借用交接流程 |

## 六、业务流程

### 6.1 器材借用流程

```
用户A发布器材 → 用户B预约器材 → 用户A确认预约 → 创建交接会话 
    → 用户A发货/当面交接 → 用户B确认收货 → 用户B使用器材 
    → 用户B归还器材 → 用户A确认收回 → 双方评价 → 完成
```

### 6.2 信用分变动场景

| 场景 | 分数变动 | 说明 |
|-----|---------|------|
| 成功出借器材 | +5 | 鼓励分享 |
| 按时归还 | +3 | 守信行为 |
| 获得好评 | +2 | 服务质量 |
| 逾期归还 | -10 | 违约惩罚 |
| 损坏器材 | -15 | 责任追究 |
| 管理员调整 | ±N | 人工干预 |

## 七、菜单配置

请在系统管理 → 菜单管理中手动添加以下菜单：

### 7.1 在商城-交易模块下添加

1. **器材预约**
   - 路由地址：reservation
   - 组件路径：mall/trade/reservation/index
   - 权限标识：product:reservation:query

2. **交接会话**
   - 路由地址：handover
   - 组件路径：mall/trade/handover/index
   - 权限标识：trade:handover:query

3. **交接详情**（隐藏）
   - 路由地址：handover/detail/:id
   - 组件路径：mall/trade/handover/detail/index
   - 是否显示：否

### 7.2 在会员模块下添加

1. **信用分管理**
   - 路由地址：credit
   - 组件路径：mall/trade/credit/index
   - 权限标识：member:credit:query

## 八、部署说明

1. **数据库**: 执行 `sql/postgresql/` 下的standalone版本SQL脚本
2. **后端**: 重新编译并启动 yudao-server
3. **前端**: 重新构建并部署 yudao-ui-admin-vue3
4. **菜单**: 在管理后台手动配置菜单
