# 训练模块说明文档

## 一、模块概述

训练模块是为自闭症谱系儿童家庭设计的家庭训练系统。采用「模板驱动 + AI 实例化」架构：

- **训练模板（骨架）**：60 个标准化训练模板，覆盖 6 大训练域
- **AI 生成（肌肉）**：根据孩子信息和模板，AI 实时生成个性化训练卡片
- **打卡记录**：记录每次训练的完成情况，为 AI 提供数据支撑

## 二、数据结构

### 2.1 训练模板 (training_template)

存储 60 个标准化训练模板，每个模板包含：

| 字段 | 说明 |
|------|------|
| code | 模板编码，如 S01, L03 |
| domain | 训练域 |
| name | 训练名称 |
| brief_goal | 简要目标 |
| recommended_frequency | 推荐频率 |
| level1_rules | L1 引导型规则 |
| level2_rules | L2 部分独立型规则 |
| level3_rules | L3 泛化挑战型规则 |

### 2.2 训练会话 (training_session)

AI 实例化出的个性化训练卡片：

| 字段 | 说明 |
|------|------|
| child_id | 孩子 ID |
| template_id | 模板 ID |
| difficulty_level | 难度等级 1/2/3 |
| ai_input_json | 传给 AI 的输入 |
| ai_output_json | AI 生成的训练卡片 |
| status | 状态：计划/进行中/完成/跳过 |

### 2.3 训练日志 (training_log)

家长打卡记录：

| 字段 | 说明 |
|------|------|
| session_id | 会话 ID |
| completed | 是否完成 |
| child_mood | 孩子情绪 |
| success_count | 成功次数 |
| difficulties | 遇到的困难 |
| ai_feedback | AI 反馈 |

## 三、训练域说明

| 域编码 | 域名称 | 模板数量 | 说明 |
|--------|--------|----------|------|
| social | 社交与互动 | 10 | S01-S10 |

| emotion | 情绪与行为 | 10 | E01-E10 |

## 四、难度等级说明

### Level 1 - 引导型
- 大人提供大量提示（语言 + 手把手 + 示范）
- 环境简化、干扰少
- 成功标准宽松，只要有接近行为就强化

### Level 2 - 部分独立型
- 减少物理帮助，主要用语言/眼神提示
- 开始要求孩子自己先尝试
- 环境略放宽，有一点点干扰也继续做

### Level 3 - 泛化挑战型
- 在更多场景中使用（不同房间、不同时间、不同人）
- 提示减少，主要等孩子主动行为
- 成功标准提高，比如连续多次成功才算达标

## 五、API 接口

### 5.1 训练模板

```
GET /member/training/template/domains     # 获取训练域列表
GET /member/training/template/list        # 获取模板列表
GET /member/training/template/get?id=1    # 获取模板详情
```

### 5.2 训练会话

```
POST /member/training/session/create      # 创建训练会话
GET  /member/training/session/get?id=1    # 获取会话详情
GET  /member/training/session/today-list  # 获取今日训练列表
GET  /member/training/session/page        # 分页查询会话
PUT  /member/training/session/start?id=1  # 开始训练
PUT  /member/training/session/skip?id=1   # 跳过训练
GET  /member/training/session/today-progress  # 获取今日进度
```

### 5.3 训练日志

```
POST /member/training/log/create          # 创建打卡记录
GET  /member/training/log/get?id=1        # 获取日志详情
GET  /member/training/log/page            # 分页查询日志
GET  /member/training/log/feedback?logId=1  # 获取 AI 反馈
GET  /member/training/log/statistics      # 获取训练统计
```

## 六、AI Prompt 设计

### 6.1 System Prompt

```
你是一名专门为自闭症谱系儿童设计家庭训练方案的治疗师助理。

你会收到一段 JSON 输入，其中包含：
- child_profile：孩子基本信息（年龄、兴趣、当前能力）
- environment：家庭环境信息（有什么材料、场景限制）
- template：训练模板元数据（目标能力、训练域、名称等）
- difficulty_level：难度等级（1=引导为主，2=部分独立，3=高泛化）

你的任务是生成一个「家庭可立即执行」的训练卡片。
```

### 6.2 输出格式

```json
{
  "title": "训练标题（面向家长）",
  "domain": "训练域",
  "goal_explained": "目标解释",
  "materials": ["材料1", "材料2"],
  "steps": ["步骤1", "步骤2"],
  "parent_script": ["建议家长说的话1"],
  "success_criteria": "成功标准",
  "reinforcement": "强化方式建议",
  "common_pitfalls": ["常见问题1"],
  "estimated_duration_minutes": 5,
  "level_hint": "当前难度说明"
}
```

## 七、用户流程

```
训练列表页 → 训练详情页 → 执行步骤页 → 打卡表单页 → AI 反馈页
```

1. **训练列表页**：展示今日训练清单，显示进度
2. **训练详情页**：展示 AI 生成的训练卡片内容
3. **执行步骤页**：逐步引导家长执行训练
4. **打卡表单页**：记录完成情况、孩子状态
5. **AI 反馈页**：展示肯定、总结和下一步建议

## 八、60 个训练模板清单

### 社交与互动（S01-S10）
- S01 回应名字
- S02 共同注意：跟随指物
- S03 展示物品给大人看
- S04 轮流：你一下我一下
- S05 模仿：拍手
- S06 模仿：敲桌子/地面
- S07 短暂对视 1 秒
- S08 主动拍大人引起注意
- S09 拉大人去需要的地方
- S10 挥手打招呼/再见

### 语言与沟通（L01-L10）
- L01 听懂"一起"
- L02 用伸手表达想要
- L03 用指物表达想要
- L04 PECS：递图片换物品
- L05 理解指令"给我"
- L06 理解"不可以"
- L07 模仿拟声词
- L08 声音轮流游戏
- L09 说"要"来请求
- L10 双词组合：要+物品

### 情绪与行为（E01-E10）
- E01 等待 5 秒
- E02 情绪识别：高兴
- E03 情绪识别：生气
- E04 用拍大人替代尖叫
- E05 深呼吸 3 次
- E06 先做 A 再做 B
- E07 用摇头表达"不"
- E08 转移注意到新活动
- E09 把大任务拆成小任务
- E10 安静坐 10 秒

### 认知与规则（C01-C10）
- C01 颜色匹配
- C02 分类：吃的 vs 玩的
- C03 大小排序：大中小
- C04 简单因果：按按钮有反应
- C05 请求帮助而不是乱爬
- C06 听从 1 步指令
- C07 听从 2 步指令
- C08 图形匹配：圆和方
- C09 规则游戏：停和走
- C10 记忆：找一找藏起来的物品

### 感觉与运动（G01-G10）
- G01 平衡木走 3 步
- G02 推墙 10 秒
- G03 触觉探索：软硬不同的物体
- G04 双脚原地跳
- G05 跨过小障碍物
- G06 精细：把吸管插进洞里
- G07 精细：捏夹子夹起物品
- G08 手眼协调：丢球进桶
- G09 身体认知：摸头摸鼻子
- G10 节奏模仿：敲敲停

### 生活自理（D01-D10）
- D01 洗手三步：开水→搓→冲
- D02 穿鞋：区分左右
- D03 穿衣：找到袖子洞
- D04 用勺挖一下吃一口
- D05 双手拿杯喝水
- D06 如厕：坐定 1 分钟
- D07 收拾玩具：放回盒子
- D08 刷牙：张嘴 5 秒
- D09 开关灯
- D10 拉拉链向上 5cm

## 十、注意事项

1. **温度细节**：所有文案用"陪孩子练"而不是"训练"
2. **不使用负面词汇**：不出现"失败"，用"今天情况有点难也没关系"
3. **保护隐私**：社区分享默认匿名
4. **降低焦虑**：每条训练给家长留"我今天只想看看"的出口
