# 星语家园 - 特殊儿童家长互助社区

一款面向特殊儿童（自闭症、发育迟缓等）家长的微信小程序，提供训练指导、经验分享、机构点评等功能。

## 功能模块

### 🏠 首页 (Home)
- 搜索框：快速搜索机构/经验/问题
- 今日微锦囊：每日推送一条实用小建议
- 金刚区入口：训练助手、经验社区、同行小组、资源黄页
- 精选经验：推荐优质家长投稿

### 💬 经验社区 (Community)
- 分类标签：全部、语言、情绪、入园、感统、社交
- 帖子列表：标题、标签、AI摘要、互动数据
- 发布功能：支持图文发布、标签选择、匿名发布
- AI摘要：自动生成帖子关键信息

### 🎯 训练助手 (Training)
- 今日任务：每日推荐的训练任务
- 周进度追踪：训练天数、时长、连续天数统计
- 历史打卡：最近7天打卡记录
- 任务详情：图文步骤指导
- 训练反馈：完成后记录孩子表现

### 👥 同行小组 (Group)
- 我的小组：已加入的互助小组
- 推荐小组：根据孩子档案智能推荐
- 小组详情：话题讨论、即时交流
- 今日话题：引导式讨论主题

### 📍 资源黄页 (Resource)
- 城市筛选：定位选择城市
- 分类筛选：感统、语言、行为、社交等
- 机构列表：名称、标签、评分、距离
- 机构详情：地址、电话、评分维度、家长点评

### 👤 我的页面 (Profile)
- 个人信息：昵称、匿名模式、孩子年龄
- 数据统计：训练天数、帖子、评论、评价
- 我的记录：训练、帖子、评论、收藏
- 工具箱：视觉计时器、训练清单等
- 孩子档案：年龄、状况、训练目标

### ⏱️ 视觉计时器
- 圆形倒计时动画
- 预设时长：1/3/5分钟
- 自定义时长
- 震动提醒

## 开发说明

### 环境要求
- 微信开发者工具
- 基础库版本 >= 3.0.0

### 开始使用
1. 下载/克隆项目
2. 打开微信开发者工具
3. 导入 `miniprogram-autism-support` 目录
4. 在 `project.config.json` 中配置 AppID

### 注意事项
- TabBar 图标需要替换为 PNG 格式 (81x81 像素)
- 部分功能为模拟数据，需对接后端 API
- 图片上传需配置云存储或服务器
