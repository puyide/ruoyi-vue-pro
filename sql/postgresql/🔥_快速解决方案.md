```

```

## ✅ 解决方案

### 方案1: 先执行系统基础SQL（推荐）

```bash

```

```bash

```


## 💡 数据字典手动配置

如果使用独立版，需要在管理后台配置以下字典：

### 1. 器材状态 (equipment_status)
- 1: 全新
- 2: 九成新
- 3: 八成新
- 4: 七成新以下

### 2. 共享类型 (share_type)
- 1: 仅赠送
- 2: 仅借用
- 3: 赠送或借用

### 3. 训练类型 (training_type)
- sensory: 感统训练
- language: 语言训练
- cognitive: 认知训练
- social: 社交训练
- fine_motor: 精细动作
- gross_motor: 大运动

### 4. 归还状态 (return_status)
- 0: 未归还
- 1: 已归还
- 2: 逾期未还
- 3: 已损坏

### 5. 信用分变动类型 (credit_change_type)
- 1: 捐赠器材 (+10分)
- 2: 按时归还 (+5分)
- 3: 逾期归还 (-10分)
- 4: 器材损坏 (-20分)
- 5: 违规行为 (-30分)
- 6: 优质评价 (+3分)
