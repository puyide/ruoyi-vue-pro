## 🔍 验证命令

在DataGrip或psql中执行：

```sql
-- 1. 检查所有表
SELECT COUNT(*) as table_count 
FROM information_schema.tables 
WHERE table_schema = 'public' 
  AND table_type = 'BASE TABLE';
-- 期望: 50+

-- 2. 检查商城数据
SELECT COUNT(*) FROM product_brand;      -- 期望: 3
SELECT COUNT(*) FROM product_category;   -- 期望: 69
SELECT COUNT(*) FROM product_spu;        -- 期望: 11

-- 3. 检查器材共享表
SELECT table_name FROM information_schema.tables 
WHERE table_name IN ('member_credit_score', 'member_credit_log', 'equipment_reservation');
-- 期望: 3行

-- 4. 检查交接会话表
SELECT table_name FROM information_schema.tables 
WHERE table_name LIKE '%handover%' OR table_name IN ('equipment_feedback', 'sensitive_keyword', 'public_location');
-- 期望: 5行

-- 5. 检查敏感词数据
SELECT COUNT(*) FROM sensitive_keyword;   -- 期望: 9

-- 6. 检查公共地点数据
SELECT COUNT(*) FROM public_location;     -- 期望: 4
```
