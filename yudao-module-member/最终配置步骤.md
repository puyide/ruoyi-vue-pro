### 步骤 1：创建 OAuth2 Client（2分钟）

在 **ruoyi 数据库**中执行以下 SQL：

```sql
-- PostgreSQL / MySQL 通用（注意 MySQL 的 NOW() 写法相同）
INSERT INTO system_oauth2_client (
  client_id, secret, name, logo, description,
  status, access_token_validity_seconds, refresh_token_validity_seconds,
  redirect_uris, authorized_grant_types, scopes, auto_approve_scopes,
  creator, create_time, updater, update_time, deleted, tenant_id
) VALUES (
  'nodebb',
  'nodebb-secret-change-me-in-production',
  'NodeBB Forum',
  '',
  'NodeBB 论坛 SSO 集成',
  0,
  604800,    -- 7天
  2592000,   -- 30天
  '["http://localhost:4567/auth/nodebb/callback"]',
  '["authorization_code","refresh_token"]',
  '["user.read"]',
  '["user.read"]',
  '1',
  NOW(),
  '1',
  NOW(),
  0,
  1
);
```

**执行方式（任选一种）：**

**方式A - 使用 GUI 工具（推荐）**
- pgAdmin / TablePlus / DataGrip
- 连接到 **ruoyi 数据库**（不是 nodebb 数据库！）
- 执行上述 SQL

**方式B - 命令行**（如果有 psql）
```bash
psql -U postgres -d ruoyi_database_name << 'SQL'
-- 粘贴上述 SQL
SQL
```

**验证：**
```sql
SELECT * FROM system_oauth2_client WHERE client_id = 'nodebb';
```

---

### 步骤 2：获取 NodeBB Master Token（1分钟）

1. 访问：http://localhost:4567/admin/settings/api
2. 点击 **Generate Token** 按钮
3. 选择 **Master Token**
4. 复制生成的 Token（格式类似：`abc123-def456-ghi789`）

---

### 步骤 3：配置 yudao 应用（2分钟）

#### 方式A：使用自动生成的配置（推荐）

编辑：`yudao-server/src/main/resources/application-nodebb-auto.yaml`

将 `master-token` 的值替换为步骤 2 获取的 Token：

```yaml
master-token: "【替换为你的Master_Token】"
```

然后在 `application-local.yaml` 中添加：

```yaml
spring:
  profiles:
    include: nodebb-auto
```

#### 方式B：直接在 application-local.yaml 中添加

```yaml
yudao:
  member:
    nodebb:
      enabled: true
      url: http://localhost:4567
      sso-secret: "T6oRQn1lIBnUo1ZhlvT11JQf8DVUnGUdHxNHCX2xPVMowDpU/CXKupAm0cqfWAGx"
      sso-cookie-name: token
      sso-cookie-domain: ""
      sso-cookie-max-age-seconds: 604800
      master-token: "【步骤2获取的Master_Token】"
      admin-uid: 1
      default-password: "DefaultPass123!"
```

### Q: Master Token 在哪里？

**答：** http://localhost:4567/admin/settings/api → Generate Token → Master Token
